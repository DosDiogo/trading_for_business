## 📋 Sobre o projeto

**T4B (Trading for Business)** é um site institucional desenvolvido como projeto final do curso de **Front End** da **Coder House**. A proposta simula a página de uma empresa que oferece serviços de trading e arbitragem automatizados, prometendo renda extra para outros negócios sem empréstimos, comissões ocultas ou letras pequenas.

O projeto foi construído com foco em:

- Layout responsivo e mobile-first
- Componentização visual com Bootstrap
- Organização de estilos com Sass
- Boas práticas de estruturação de páginas HTML

> ⚠️ Projeto educacional. O conteúdo e os serviços apresentados são fictícios e foram criados exclusivamente para fins de aprendizado.

## 🖥️ Páginas do site

| Página | Descrição |
|---|---|
| `index.html` | Página inicial com apresentação da empresa, como funciona o serviço, depoimentos de clientes e links para download do app |
| `pages/software.html` | Detalhes sobre o software/serviço de trading |
| `pages/nosotros.html` | Sobre a empresa |
| `pages/contacto.html` | Formulário e informações de contato |
| `pages/sucursales.html` | Filiais/unidades da empresa |

## ✨ Funcionalidades

- 🧭 Menu de navegação responsivo (Navbar com toggler para mobile)
- 📊 Seção "Como funciona" explicando análise, cálculos, arbitragem e trading
- 💬 Carrossel de depoimentos de clientes
- 📱 Botões de download para Google Play e App Store
- 📞 Seção de contato e redes sociais no rodapé
- 💚 Botão flutuante de WhatsApp

## 🛠️ Tecnologias utilizadas

- **HTML5** — estruturação semântica das páginas
- **CSS3 / Sass (SCSS)** — estilização e organização modular de estilos
- **Bootstrap 5.3.3** — grid system e componentes responsivos
- **Font Awesome** — ícones (redes sociais, WhatsApp, etc.)
- **JavaScript** — interações da interface

## 🚀 Como executar o projeto

Como se trata de um site estático (HTML/CSS/JS), não há necessidade de instalação de dependências para visualizá-lo.

```bash
# Clone o repositório
git clone https://github.com/DevDos-tech/trading-for-business.git

# Acesse a pasta do projeto
cd trading-for-business

# Abra o arquivo index.html no navegador de sua preferência
```

Para uma melhor experiência de desenvolvimento (com live reload), recomenda-se usar a extensão **Live Server** do VS Code ou similar.

Se estiver utilizando os arquivos `.scss`, compile-os com o Sass:

```bash
sass sass/estilos.scss css/estilos.css --watch
```
